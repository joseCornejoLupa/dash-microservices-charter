NOTA CRÍTICA SOBRE LA MÉTRICA J/tx
------------------------------------------------------------
La métrica energy_per_tx = total_energy_J / successful_tx incluye energía idle del
cluster (ecofloc mide el nodo entero, no solo TeaStore). Cuando el throughput
difiere marcadamente entre grupos (aquí ~70% menos para con-plugin), la J/tx
amplifica artificialmente la diferencia. Para el impacto energético bruto del
plugin, total_energy_J es más honesta (siempre que la duración sea comparable).
Base científica: SCI de Green Software Foundation (GSF 2023) / ISO/IEC 21031:2024.

Alternativas más robustas:
  - Energía bruta (total_energy_J): más honesta para comparar el plugin
  - Potencia media (total_energy_J / duration_s): comparable entre duraciones distintas
  - Throughput energético (successful_tx / total_energy_J en tx/J): versión invertida intuitiva
  - Energía diferencial ((E_cluster − E_baseline) / successful_tx): requiere medición idle
